Spinners

Indicate the loading state of a component or page with Bootstrap spinners, built entirely with HTML, CSS, and no JavaScript.

About

Bootstrap “spinners” can be used to show the loading state in your projects. They’re built only with HTML and CSS, meaning you don’t need any JavaScript to create them. You will, however, need some custom JavaScript to toggle their visibility. Their appearance, alignment, and sizing can be easily customized with our amazing utility classes.

For a spinner that follows Google Material Design, use Material’s circular progress indicator (.progress-circular) instead. Bootstrap’s spinners are lighter: a single element each, which makes them handy inside buttons and other small components.

For accessibility purposes, each loader here includes role="status" and a nested <span class="sr-only">Loading...</span>.

The animation of spinners depends on the prefers-reduced-motion media query. When a user has asked for reduced motion, Material slows spinners down rather than stopping them, since a spinner that doesn’t move no longer says “loading”.

Spinners in Bootstrap are built with rems, currentColor, and display: inline-block. This means they can easily be resized, recoloured, and quickly aligned.
